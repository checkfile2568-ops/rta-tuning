โหมดมือถืออย่างเดียว

ใช้มือถือเครื่องเดียว วัด + ดูคำแนะนำ แล้วเอาค่าไปกรอก BlueArt — ไม่ต้องตั้ง WiFi

ป้อนเสียงเข้าระบบ (ไร้สาย)

  1. จับคู่ มือถือ → Bluetooth → BlueArt
  2. ในมือถือปิด EQ/เพิ่มเสียงให้หมด (flat) เร่งวอลุ่มบลูทูธพอฟัง
  3. กด 📻 Pink Noise ในเว็บนี้ → เสียงวิ่งเข้าลำโพง ไมค์วัดพร้อมกัน

วัด + ปรับ

  1. ถือมือถือเดินทั่วโซนฟัง กด 🚶 เดินวัด · MMM 30 วิ
  2. อ่านคำแนะนำ → จดค่า (💾 พรีเซ็ต) → ไปกรอกลง BlueArt (แอปบลูทูธของแอมป์)
เหมาะกับจูนเร็ว/หน้างาน · ดีเลย์บลูทูธไม่กระทบ RTA/MMM/เช็กเฟส (วัด “ระดับ” ไม่ใช่ “เวลา”)

โหมดคอม + มือถือ (แบ่งหน้าที่)

คอม = Smaart (เฟส/ดีเลย์/อ้างอิงคาลิเบรต) · มือถือ = เว็บนี้ (MMM ภาคสนาม) — ยืนจุดฟังจุดเดียว วัด+ปรับพร้อมกันผ่าน WiFi วงเดียวกัน

① ตั้ง WiFi ให้อยู่วงเดียวกัน

  1. ให้ มือถือ + คอม เกาะ WiFi ตัวเดียวกัน (เราเตอร์/ตู้ตัวเดียว) — หรือปล่อยฮอตสปอตจากมือถือ แล้วให้คอมมาเกาะ
  2. เช็กว่าอยู่วงเดียวกัน: IP ต้องขึ้นต้นเหมือนกัน เช่น 192.168.1.x ทั้งคู่ (คอมดู ipconfig · มือถือดูในตั้งค่า WiFi)

② คุมจอคอมจากจุดฟัง

  1. ลง Chrome Remote Desktop (หรือ AnyDesk) ทั้งคอมและมือถือ — Chrome RD ใช้บัญชี Google เดียวกันทั้งสองเครื่อง
  2. รีโมทจากมือถือเข้าคอม → ยืนจุดฟัง: วัดด้วยเว็บนี้ + ปรับ Smaart/EQ บนคอม พร้อมกัน ไม่ต้องเดินกลับ

③ ถ้าใช้ DSPico2.6 (ออปชัน)

  1. ตั้ง DSPico ให้ เกาะเราเตอร์ตัวเดียวกัน (IP Type = DHCP) → โปรแกรม DSPico บนคอมเจอเครื่องเอง คอมยังต่อเน็ตได้
  2. เลี่ยงต่อ AP ของ DSPico ตรงๆ (SSID DSPico2.6-RACK-xxxx / รหัส 123456789) เพราะคอมจะหลุดเน็ต
แบ่งงาน: เฟส/ดีเลย์ที่ต้องเป๊ะ → Smaart (มี reference channel) · MMM หลายจุด/เช็กเร็ว → เว็บนี้

ตู้ปัจจุบัน — bandpass ออเดอร์ 4

ดอกติดกลับด้านบนแผ่นกั้น · ฝั่งกรวย = ห้องปิด · ฝั่งแม่เหล็ก (เห็นผ่านอะคริลิก) = ห้องมีช่องลม → เบสออกทางตะแกรงซ้าย · ห้องแอมป์แยก

1 เช็กตัวตู้ก่อนจูน
หารอยรั่วเปิดโทน 40–50Hz ระดับกลาง เอาทิชชูไล่รอบขอบอะคริลิก หัวสกรู รูสาย · ลมพ่น/เสียงซี่ = รั่ว → อัดยาง/ซิลิโคน
ห้องปิดฝั่งกรวยต้องสนิท 100% — รั่วนิดเดียวเบสหลวมทันที
ห้องแอมป์/กลาง/แหลมแยกลมจากห้องซับ · รูลอดสายอุดซิลิโคน
อะคริลิกเร่งแล้วต้องไม่สั่น/ตบ · ถ้าย้วยเพิ่มสกรูหรือคานค้ำ
2 Gain staging (กันเร่งแล้วแตก)
มือถือ85–90% · ปิด EQ ในมือถือ
ปุ่มหลังตู้BASS / MID / TREBLE ไว้ตรงกลาง (flat) · ใช้ VOL คุมหลัก
⚠ BASS หมุนขึ้นค้าง = บูสต์ซ้อนกับ DSP แอมป์คลิปเร็ว
3 ตั้ง DSP ตามลำดับ
①Reset EQ ทุกช่อง
②ครอส: ซับ LPF 90–100 LR24 · กลาง 120 / 3.9k · แหลม 3.9k LR12
③🌊 Sweep จ่อตะแกรงซ้าย → subsonic ≈ 0.7 × พีค (≥30Hz) · BW24
④🔄 เช็กเฟสซับ 0/180 ที่จุดตัด · ยังดิพ → ดีเลย์ทีละ 0.5ms
⑤เลเวล: ซับสูงกว่ากลาง ~+6dB (เป้า ดีสแต็ก)
⑥🚶 MMM → ตัดโหนกเบส · ≤5 แบนด์ · บูสต์ ≤ +3dB
⑦Limiter (ตารางล่าง) → เร่งดูดอกผ่านช่องโครง → A/B → เซฟ 2 พรีเซ็ต (ในบ้าน/กลางแจ้ง)
4 Limiter เริ่มต้น
แหลม 2"Thresh −6 dB · Hold FAST · Release NORMAL
กลาง 4" (50W/แอมป์80W)Thresh −4 dB · Hold NORMAL · Release NORMAL
ซับThresh −2 ถึง −3 dB · Hold FAST · Release NORMAL
ค่าเริ่มต้น — ฟังแล้วอัด/ไม่ดังขึ้น ค่อยยก threshold ทีละ 1dB
🔴 ดูดอกผ่านช่องโครงสีเหลือง: ขยับเยอะผิดปกติหรือมีเสียงกึก = ถึงเพดาน ตั้ง limiter ตรงนั้น · แอมป์ซับ UCD-1500 จ่ายได้มากกว่าที่ดอกรับไหว (ยิ่งต่อ 2Ω ยิ่งแรง) → limiter ช่องซับคือตัวกันดอกพัง
คำแนะนำการจูน (รู้จักระบบ 3 ทาง)
ป้อนครอสตามการ์ดด้านบนก่อน แล้วกด เริ่มวัดด้วยไมค์ → เปิด Pink Noise เข้าระบบ → วางมือถือระดับหูตำแหน่งฟัง → กด วัดผล ระบบจะวิเคราะห์เทียบเป้าหมาย “ดีสแต็ก” และบอกจุดที่ควรปรับ
ลำดับการจูนชุด 3 ทางนี้
  1. หาจูนตู้ก่อน: กด Sweep เบส กวาด 20–160Hz — ระบบจะบอกความถี่ที่ตู้ดังสุด (จูนตู้) และแนะนำจุดตั้ง Subsonic ให้อัตโนมัติ เอาไปตั้งช่องซับ
  2. ครอส: ตั้งครอส/subsonic ตามการ์ด+ผล Sweep บน Blue Art — subsonic สำคัญมากกับตู้ bandpass กันดอกซับหลุดใต้ย่านที่ตู้เล่นได้จนพัง · Sweep ให้จ่อไมค์ที่ช่องลมตะแกรงซ้าย
  3. เฟส/ดีเลย์: เล่น Pink Noise วัดรอบจุดตัด 100Hz กับ 4kHz — ถ้าเป็นดิพลึก ลองสลับโพลาริตี้/ปรับดีเลย์ ให้ไดรเวอร์มาถึงหูพร้อมกันก่อน อย่าเพิ่งดันด้วย EQ
  4. เลเวลสมดุล: ปรับเกนซับ/กลาง/แหลม ให้เส้นเสียงจริงราบใกล้เป้าหมาย
  5. EQ ละเอียด: ค่อยจูน PEQ ตามที่ระบบแนะนำ เน้นตัด (subtractive) มากกว่าบูสต์
  6. วัดซ้ำจนพอใจ → Save Preset บน DSP (ทำหลายพรีเซ็ต: ฟังเพลิน / ประกวด / ประกาศ)
อาการเบสแตกตอนเร่ง (แก้ตามลำดับ): ① ตั้ง Subsonic HPF ตามค่า 🌊 Sweep (~0.7×พีค) Butterworth ชันๆ — กันดอกซับหลุดใต้จูนตู้ (สาเหตุอันดับ 1 ของเสียงแตก) ② เช็ก amp คลิปไหม ตั้งเกน+Limiter สับให้เอาต์พุตไม่ดันแอมป์คลิป ③ อย่าบูสต์ต่ำกว่าที่ตู้เล่นได้ — ตู้ bandpass ออเดอร์ 4 เป็นตู้แบนด์แคบ บูสต์ 30–45Hz มีแต่ทำดอกสะบัด/แตก ให้ตัดพีคของตู้แล้วเร่งเกนรวมแทน จะดังสะอาดกว่า

หมายเหตุ: Blue Art มี RTA/Spectrum ในตัว และเครื่องพี่มี Smaart Suite ด้วย — ถ้ามีไมค์วัดคาลิเบรต ใช้ Smaart จะเที่ยงสุด · ตัวนี้ไว้เช็กเร็ว/พกพา + ได้เส้นเป้าหมายและคำแนะนำอัตโนมัติที่ RTA ในตัวไม่มี แล้วเอาค่าไปใส่ Blue Art ตามฟอร์แมต Band/F/Q/G ได้เลย

จุดอ่อนที่ต้องจับตาในชุดนี้: ไม่มีมิดเบสแยก — 10" ตู้ bandpass ออเดอร์ 4 เป็นตู้แบนด์แคบ (ขึ้นไม่ค่อยถึง 150–300Hz) ส่วน 4" ก็ยังไม่เต็มที่ในย่านนั้น ทำให้ช่วง 150–300 Hz มักตก ฟังแล้วเสียงบาง/ขาดเนื้อ · แก้โดยขยับ LP ซับขึ้นเล็กน้อยหรือ HP กลางลง แล้วหนุน PEQ เบาๆ · และไมค์มือถือไม่ได้คาลิเบรต ค่าที่อ่านเป็นแนวโน้ม ถ้าอยากเป๊ะใช้ UMIK-1 + REW (ฟรี)
