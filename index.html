โหมดมือถืออย่างเดียว

ใช้มือถือเครื่องเดียววัด + ลองค่าในหน้า 🎛️ DSP เสมือน แล้วค่อยเอาค่าไปกรอกใน DSPico บนโน้ตบุ๊กทีหลัง

ป้อนเสียงเข้าระบบ (ไร้สาย)

  1. จับคู่ มือถือ → Bluetooth → บอร์ด D-STACK (เสียงเข้าทางบลูทูธ LDAC)
  2. ในมือถือปิด EQ/เพิ่มเสียงให้หมด (flat) เร่งวอลุ่มบลูทูธพอฟัง
  3. กด 📻 Pink Noise ในเว็บนี้ → เสียงวิ่งเข้าลำโพง ไมค์วัดพร้อมกัน

วัด + ลองค่า + บันทึก

  1. ถือมือถือเดินทั่วโซนฟัง กด 🚶 เดินวัด · MMM 35 วิ
  2. เปิด 🎛️ DSP เสมือน → ปรับครอส/EQ/เกน ดูเส้นส้ม “คาดว่าจะได้” จนเข้าเป้า → 💾 บันทึก
  3. กด 📋 คัดลอกค่า ส่งเข้า LINE/โน้ต ไว้กรอกใน DSPico
เหมาะกับจูนเร็ว/หน้างาน · ดีเลย์บลูทูธไม่กระทบ RTA/MMM/เช็กเฟส (วัด “ระดับ” ไม่ใช่ “เวลา”)

โหมดคอม + มือถือ (ตั้งค่าจริงผ่าน WiFi)

โน้ตบุ๊ก = โปรแกรม DSPico คุมบอร์ด D-STACK · มือถือ = เว็บนี้ (วัด + จำลอง) — ทุกเครื่องอยู่ WiFi บ้านวงเดียวกัน ปรับแล้ววัดซ้ำได้ทันที

① ให้ทุกเครื่องอยู่ WiFi วงเดียวกัน

  1. บอร์ด D-STACK ตั้งเป็น WIFI Client Mode เกาะ WiFi บ้าน (IP Type = DHCP) — ตั้งครั้งเดียว บอร์ดจำไว้
  2. โน้ตบุ๊ก + มือถือ เกาะ WiFi บ้านตัวเดียวกัน · ใน DSPico เลือกการ์ดเครือข่ายเป็น Wi-Fi (ไม่ใช่ vEthernet) แล้วค้นหาอุปกรณ์
  3. เช็กวงเดียวกัน: IP ขึ้นต้นเหมือนกัน เช่น 192.168.1.x (คอมดู ipconfig · มือถือดูในตั้งค่า WiFi)
  4. ถ้าหาบอร์ดไม่เจอ: ต่อ WiFi ของบอร์ดเองตรงๆ (AP · IP 192.168.10.1) — ใช้ได้แต่คอมจะหลุดเน็ตชั่วคราว

② รอบจูน: ลองในเว็บ → กรอกจริง → วัดยืนยัน

  1. มือถือ: วัด 📸/🚶 แล้วลองค่าใน 🎛️ DSP เสมือน จนเส้นส้มเข้าเป้า
  2. โน้ตบุ๊ก: กรอกค่าเดียวกันใน DSPico (ครอส · PEQ ชนิด/F/Q/G · เกน · เฟส · ดีเลย์ · Limiter)
  3. มือถือ: วัดซ้ำ → เส้นจริงควรทับเส้นส้ม → 📈 เก็บกราฟ + 💾 บันทึก
  4. อยากวางมือถือวัดที่จุดฟัง แล้วกดสั่งจากคอมข้าง DSPico: กด 🧭 รูปแบบ → มือถือเลือก 📍 เครื่องวัด · คอมเลือก 🎮 แผงควบคุม (ต้องตั้งค่าซิงก์ทั้งสองเครื่อง) · คอมสั่งวัด / Pink Noise / อัดวิดีโอ แล้วเห็นผลและคำแนะนำทันที

③ 📡 โหมดรีโมต: คอมรับเสียง · มือถือควบคุม

  1. ตั้งค่า 🔄 ซิงก์ (Firebase) ทั้งสองเครื่อง ใช้ config + ชื่อห้องเดียวกัน
  2. คอม: หน้า 📊 วัด → แถบ “โหมดรีโมต” เลือก 💻 เครื่องนี้รับเสียง · วางคอม/ไมค์ไว้ที่จุดฟัง
  3. มือถือ: เลือก 🎮 เครื่องนี้เป็นรีโมต → กด 📻 Pink (เล่นจากมือถือผ่านบลูทูธ) → กด 🎙️ / 📸 / 🚶 / 🌊 สั่งคอมได้เลย กราฟสดขึ้นบนมือถือทันที
  4. ไมค์คอมต้องปิดตัวปรับเสียง: Windows → ตั้งค่า → ระบบ → เสียง → ไมโครโฟน → ปิด Audio enhancements / ลดเสียงรบกวน · ถ้ามีไมค์วัด USB (เช่น UMIK-1) ใช้ตัวนั้นจะแม่นที่สุด
มี Smaart Suite: ใช้ตอนต้องการเฟส/ดีเลย์แม่นระดับ ms ร่วมกับไมค์วัดคาลิเบรต · งานประจำ (MMM/EQ/เกน) ใช้เว็บนี้พอ

ขั้นตอนจูน (กรอกค่าเข้า DSPico)

ทำเรียง 3 → 4 → 5 ห้ามสลับ · วัดด้วย 📸 หรือ 🚶 ก่อนกรอกทุกครั้ง

3 ครอสโอเวอร์ + สโลป
ซับ 10"subsonic ≈0.7×พีค Sweep (≥30Hz) · LPF 90–100Hz · LR24
กลาง 4"×2HPF 120Hz · LPF 3.91k · LR24
แหลม 2"×2HPF 3.91k · LR24 (เฟสปกติ)
ใส่ที่ช่อง HPF และ LPF ของแต่ละแชนแนล (เลือกความถี่ + ชนิด/สโลป)
⚠ อย่าลืม subsonic HPF ที่ซับ — ตู้ bandpass ขาดตัวนี้ดอกพังได้
4 เฟส / ดีเลย์
เฟสซับสลับ 0 ↔ 180 → เลือกอันดังกว่าที่จุดตัด (ใช้ 🔄 เช็กเฟส)
ดีเลย์ตั้ง Delay align เวลา 3 ทาง ให้เสียงลงตัว (บอร์ด D-STACK ทำได้ในตัว)
ตั้ง Delay และ Phase ต่อแชนแนลในโปรแกรม DSPico (โน้ตบุ๊ก · WiFi) · ลองค่าก่อนได้ในหน้า 🎛️ DSP เสมือน
💡 อยากเป๊ะระดับวัดจริง: หา delay/เฟส ด้วย Smaart แล้วเอาค่ามากรอกใน DSPico
5 เลเวลสมดุล 3 ทาง
เกนปรับซับ/กลาง/แหลม ให้เส้นจริงเข้าหาเส้นเป้า (วัด MMM)
ใส่ที่ช่อง Gain / Volume ต่อแชนแนล
⚠ อย่าดันเกนจนคลิป · ตัดพีคก่อน แล้วค่อยเร่งรวม

ตู้ปัจจุบัน — bandpass ออเดอร์ 4

ดอกติดกลับด้านบนแผ่นกั้น · ฝั่งกรวย = ห้องปิด · ฝั่งแม่เหล็ก (เห็นผ่านอะคริลิก) = ห้องมีช่องลม → เบสออกทางตะแกรงซ้าย · ห้องแอมป์แยก

1 เช็กตัวตู้ก่อนจูน
หารอยรั่วเปิดโทน 40–50Hz ระดับกลาง เอาทิชชูไล่รอบขอบอะคริลิก หัวสกรู รูสาย · ลมพ่น/เสียงซี่ = รั่ว → อัดยาง/ซิลิโคน
ห้องปิดฝั่งกรวยต้องสนิท 100% — รั่วนิดเดียวเบสหลวมทันที
ห้องแอมป์/กลาง/แหลมแยกลมจากห้องซับ · รูลอดสายอุดซิลิโคน
อะคริลิกเร่งแล้วต้องไม่สั่น/ตบ · ถ้าย้วยเพิ่มสกรูหรือคานค้ำ
2 Gain staging (กันเร่งแล้วแตก)
มือถือ85–90% · ปิด EQ ในมือถือ
ปุ่มหลังตู้BASS / MID / TREBLE ไว้ตรงกลาง (flat) · ใช้ VOL คุมหลัก
⚠ BASS หมุนขึ้นค้าง = บูสต์ซ้อนกับ DSP แอมป์คลิปเร็ว
3 ตั้ง DSP ตามลำดับ
①Reset EQ ทุกช่อง
②ครอส: ซับ LPF 90–100 LR24 · กลาง 120 / 3.9k LR24 · แหลม 3.9k LR24
③🌊 Sweep จ่อตะแกรงซ้าย → subsonic ≈ 0.7 × พีค (≥30Hz) · BW24
④🔄 เช็กเฟสซับ 0/180 ที่จุดตัด · ยังดิพ → ดีเลย์ทีละ 0.5ms
⑤เลเวล: ซับสูงกว่ากลาง ~+6dB (เป้า ดีสแต็ก)
⑥🚶 MMM → ตัดโหนกเบส · ≤5 แบนด์ · บูสต์ ≤ +3dB
⑦Limiter (ตารางล่าง) → เร่งดูดอกผ่านช่องโครง → A/B → เซฟ 2 พรีเซ็ต (ในบ้าน/กลางแจ้ง)
4 Limiter เริ่มต้น
แหลม 2"Thresh −6 dB · Hold FAST · Release NORMAL
กลาง 4" (50W/แอมป์80W)Thresh −4 dB · Hold NORMAL · Release NORMAL
ซับThresh −2 ถึง −3 dB · Hold FAST · Release NORMAL
ค่าเริ่มต้น — ฟังแล้วอัด/ไม่ดังขึ้น ค่อยยก threshold ทีละ 1dB
🔴 ดูดอกผ่านช่องโครงสีเหลือง: ขยับเยอะผิดปกติหรือมีเสียงกึก = ถึงเพดาน ตั้ง limiter ตรงนั้น · แอมป์ซับ UCD-1500 จ่ายได้มากกว่าที่ดอกรับไหว (ยิ่งต่อ 2Ω ยิ่งแรง) → limiter ช่องซับคือตัวกันดอกพัง
ลำดับการจูนชุด 3 ทางนี้
  1. หาจูนตู้ก่อน: กด Sweep เบส กวาด 20–160Hz — ระบบจะบอกความถี่ที่ตู้ดังสุด (จูนตู้) และแนะนำจุดตั้ง Subsonic ให้อัตโนมัติ เอาไปตั้งช่องซับ
  2. ครอส: ตั้งครอส/subsonic ตามการ์ด+ผล Sweep ใน DSPico — subsonic สำคัญมากกับตู้ bandpass กันดอกซับหลุดใต้ย่านที่ตู้เล่นได้จนพัง · Sweep ให้จ่อไมค์ที่ช่องลมตะแกรงซ้าย
  3. เฟส/ดีเลย์: เล่น Pink Noise วัดรอบจุดตัด 100Hz กับ 4kHz — ถ้าเป็นดิพลึก ลองสลับโพลาริตี้/ปรับดีเลย์ ให้ไดรเวอร์มาถึงหูพร้อมกันก่อน อย่าเพิ่งดันด้วย EQ
  4. เลเวลสมดุล: ปรับเกนซับ/กลาง/แหลม ให้เส้นเสียงจริงราบใกล้เป้าหมาย
  5. EQ ละเอียด: ค่อยจูน PEQ ตามที่ระบบแนะนำ เน้นตัด (subtractive) มากกว่าบูสต์
  6. วัดซ้ำจนพอใจ → 💾 บันทึกชุดจูนในเว็บ + Save Preset ใน DSPico (ทำหลายชุด: ฟังเพลิน / กลางแจ้ง / ประกาศ)
