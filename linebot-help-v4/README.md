| ชั้น | ส่วนประกอบ |

| ประตูทางเข้า | `doPost` รับ webhook จาก LINE · `doGet` เปิด Dashboard (ตรวจรหัสฝั่งเซิร์ฟเวอร์) |

| ข้อมูล | Google Sheets หลัก 20 แท็บ · ไฟล์ฐานค้นหาแยก 7 ไฟล์ · โฟลเดอร์ Drive เก็บรูปหลักฐาน |

2. **ค่าในชีต `ตั้งค่า` มีผลทันที · โค้ดที่แก้ไม่มีผลจนกว่าจะ Deploy เป็นเวอร์ชันใหม่**

## 2. Flow — ข้อความหนึ่งข้อความเดินผ่านอะไรบ้าง

ลำดับจริงในโค้ด ใครรับก่อนได้ก่อน แล้วจบทันที

```
1.  LINE ส่ง webhook  →  doPost
2.  ลงทะเบียนเจ้าหน้าที่   (เฉพาะแชทส่วนตัว)
3.  คำสั่งพิเศษ            /ไอดีกลุ่ม /ช่วยเหลือ /help และคำสั่ง Admin
4.  รูปภาพ / พิกัด         เข้าระบบงานหมายทันที
5.  บันทึกส่วนตัว · ศูนย์คดีออนไลน์ · ข้อมูลทั่วไป
6.  บัญชีนัดความ          ⛔ ด่านสิทธิ์: ตาม COURT_ACCESS (ปัจจุบัน vip)
7.  บอท AI                ⛔ ด่านสิทธิ์: ตาม BOT_ACCESS (ค่าเริ่มต้น vip)
8.  ค้นหาฐานข้อมูล        ⛔ ด่านสิทธิ์รายฐาน ปิดไว้ก่อนถ้าค่าไม่ถูกต้อง (ดูข้อ 3)
9.  ไม่มีใครรับ           ตอบ "ไม่พบข้อมูล" · log = Fallback / NotFound
```

**จุดที่เข้าใจผิดบ่อยที่สุด:** `ช่วยหา` กับ `สอบถาม` ทำงาน **เหมือนกันทุกประการ** ไปที่ระบบเดียวกัน ได้ผลเดียวกัน สิ่งที่ทำให้ผลต่างกันคือ *เนื้อหาคำถาม* ไม่ใช่คำนำหน้า

## 3. ระบบสิทธิ์ 3 ระดับ

| ความสามารถ | ทั่วไป | VIP | Admin | ตั้งค่าที่ |
|---|:--:|:--:|:--:|---|
| บอท AI (`ช่วยหา` / `สอบถาม`) | ✗ | ✓ | ✓ | ชีต `ตั้งค่า` แถว `BOT_ACCESS` |
| ฐาน: ต่อเนื่อง · คำขอคัดถ่าย · เบอร์ทนาย · เวรเสื้อฟ้า · เขตส่งหมาย | ✗ | ✓ | ✓ | ชีต `ฐานค้นหา` คอลัมน์ **สิทธิ์** = `Internal` |
| ฐาน: ผู้ใหญ่บ้าน · ส่งหมาย | ✗ | ✗ | ✓ | ชีต `ฐานค้นหา` คอลัมน์ **สิทธิ์** = `Admin` |
| บัญชีนัดความ | ✗ | ✓ | ✓ | `COURT_ACCESS` |
| ส่งรูปหลักฐาน · ส่งพิกัด | ✓ | ✓ | ✓ | `PHOTO_ALLOWED_IDS` / จำกัดตามกลุ่ม |
| ข้อมูลทั่วไป · ศูนย์คดีออนไลน์ · คู่มือ | ✓ | ✓ | ✓ | เปิดทุกคน |
| คำสั่งผู้ดูแล 9 คำสั่ง | ✗ | ✗ | ✓ | แท็บ `GROUP_WHITELIST` |

### ⚠️ ความขัดแย้งที่ยังคงอยู่ แต่แก้เองได้แล้ว

คำสั่ง `/ค้นหา` ถูกตั้งเป็นระดับ **USER** (เปิดให้ทุกคน) แต่ปัจจุบัน **ทุกฐานข้อมูลยังตั้งเป็น `Internal` หรือ `Admin`** จึงปิดกั้นผู้ใช้ทั่วไปอยู่

ผลคือผู้ใช้ทั่วไปใช้คำสั่งได้แต่ไม่เจออะไรเลย และไม่รู้ว่าตัวเองไม่มีสิทธิ์ — นึกว่าไม่มีข้อมูลหรือระบบเสีย

ตั้งแต่เวอร์ชัน 286 เรื่องนี้แก้ได้จากชีตโดยไม่ต้องแตะโค้ด: เปลี่ยนคอลัมน์ **สิทธิ์** ของฐานที่ต้องการให้เป็น `All` ผลมีทันที

### ⚠️ ชื่อแท็บที่ชวนเข้าใจผิด

แท็บชื่อ `GROUP_WHITELIST` **ไม่ใช่รายชื่อกลุ่ม** — ข้างในคือตารางสิทธิ์ของคำสั่ง 12 รายการ ว่าคำสั่งไหนเป็นระดับ USER หรือ ADMIN

### กลไกการเปรียบเทียบสิทธิ์ฐานข้อมูล (เปลี่ยนในเวอร์ชัน 286)

โค้ดอ่านคอลัมน์ **สิทธิ์** ผ่านตัวช่วยที่ตัดช่องว่าง ตัดอักขระแฝงที่มองไม่เห็น และไม่สนใจตัวพิมพ์เล็กพิมพ์ใหญ่

| ค่าที่พิมพ์ | ผลลัพธ์ |
|---|---|
| `All` · `all` · `ทุกคน` | เปิดให้ทุกคน |
| `Internal` · `internal` · `VIP` | ต้องเป็น VIP ขึ้นไป |
| `Admin` · `admin` | ต้องเป็น Admin |
| **ค่าอื่นทั้งหมด รวมทั้งเว้นว่างและพิมพ์ผิด** | **ถือเป็น Admin — ปิดไว้ก่อน** |

แถวสุดท้ายคือหัวใจของการเปลี่ยนครั้งนี้ ก่อนหน้านี้ระบบเป็นแบบ *fail-open* คือพิมพ์ `internal` ตัวเล็กหรือสะกดผิดตัวเดียว ฐานนั้นจะเปิดสาธารณะทันทีโดยไม่มีอะไรเตือน ซึ่งกลับด้านกับที่ควรเป็นสำหรับข้อมูลที่มีชื่อบุคคล

ตอนนี้เป็น *fail-closed* แทน — พิมพ์ผิดแล้วฐานจะ**หายไปจากผลค้นหา** ไม่ใช่เปิดให้คนนอก ถ้าฐานไหนหายไป ให้ตรวจคำในคอลัมน์นี้เป็นอย่างแรก

คอลัมน์ **สถานะ** ก็ผ่านตัวช่วยเดียวกัน จึงพิมพ์ `ON` `on` หรือ `On` ได้เหมือนกันหมด

### สิทธิ์บอท AI ตั้งจากชีตได้แล้ว

ชีต `ตั้งค่า` แถว `BOT_ACCESS`

| ค่า | ใครถามบอทได้ |
|---|---|
| `all` | ทุกคน |
| `vip` | VIP และ Admin — **ค่าเริ่มต้น** |
| `admin` | Admin เท่านั้น |

ถ้าไม่มีแถวนี้ หรือพิมพ์ค่าที่ระบบไม่รู้จัก ระบบจะใช้ `vip` ซึ่งตรงกับพฤติกรรมเดิมทุกประการ

| ต้องการทำอะไร | พิมพ์ | ระดับ |

| ค้นฐานข้อมูล (แชทส่วนตัว) | `ค้นหา 89/9` | VIP |
| ค้นฐานข้อมูล (ในกลุ่ม) | `บอท ค้นหา 89/9` | VIP |
| ดูรายชื่อฐาน | `ค้นหา ฐาน` | VIP |
| ถามบอท AI | `ช่วยหา …` หรือ `สอบถาม …` | ตาม `BOT_ACCESS` |
| ถามบอท AI ในกลุ่ม | `บอท ช่วยหา …` | ตาม `BOT_ACCESS` |
| บัญชีนัดวันนี้ | `บัญชีนัดความ วันนี้` | VIP |
| บัญชีนัดวันอื่น | `บัญชีนัดความ 17 ส.ค. 69` | VIP |

| บันทึกงานหมาย | ส่งรูป → ส่งตำแหน่ง → พิมพ์เลขที่บ้าน | ทุกคน |
| ดูไอดีกลุ่ม | `/ไอดีกลุ่ม` | Admin |

| คำสั่งผู้ดูแล | `/สอน` `/แก้ไข` `/ลบ` `/รายการ` `/สถิติ` `/จำนวนรวม` `/แจ้งเตือน` `/บอท` | Admin |

### บัญชีนัดยืดหยุ่นกว่าที่คู่มือเดิมระบุ

รับได้ **4 คำนำหน้า** — `บัญชีนัดความ` · `บัญชีนัด` · `นัดความ` · `นัด`

ตามด้วย `วันนี้` `พรุ่งนี้` `มะรืน` `เมื่อวาน` หรือวันที่ในรูปแบบใดก็ได้

**เว้นวรรคหรือไม่เว้นก็ได้** และ **ไม่ต้องมีคำว่า `บอท` นำหน้า**

## 5. การลงทะเบียนเป็นเจ้าหน้าที่

วิธีเดียวที่เปิดสิทธิ์ให้คนใช้ระบบได้เต็มที่ — ทำได้เองโดยไม่ต้องแก้โค้ด

1. ทักบอทใน **แชทส่วนตัว** (พิมพ์ในกลุ่มจะไม่ทำงาน เพื่อไม่ให้รหัสโผล่ให้คนทั้งกลุ่มเห็น)
2. พิมพ์รหัสลับ — ขอจาก Admin
3. บอทถามชื่อ (พิมพ์ `/ยกเลิก` ได้ถ้าเปลี่ยนใจ)
4. พิมพ์ชื่อ-นามสกุล → ระบบตั้งสิทธิ์เป็น VIP ทันที

**หมายเหตุ:** สมาชิกที่ยังมีชื่อในระบบเป็น `User_2`, `User_13` ฯลฯ คือคนที่ยังไม่เคยลงทะเบียน และเป็นกลุ่มที่ค้นอะไรไม่ได้เลย

## 6. ข้อจำกัดที่ต้องรู้

### ค้นอินเทอร์เน็ตใช้ไม่ได้ และเปิดไปก็ไม่ช่วย

โมเดลค้นเว็บตอบกลับ `HTTP 429` ทุกครั้ง เพราะโควตา grounding เป็นศูนย์จนกว่าจะผูกบัญชีเรียกเก็บเงินกับ Google

ปัจจุบันสวิตช์ปิดอยู่จึงไม่กระทบอะไร — **ถ้าเปิดจะทำให้ทุกคำถามช้าขึ้นราว 4 วินาทีโดยไม่ได้อะไรกลับมา**

### ข้อมูลบัญชีนัดมีเป็นช่วง ต้องนำเข้าเรื่อย ๆ

ถามวันที่นอกช่วงที่นำเข้าไว้จะได้การ์ด "ยังไม่มีข้อมูลในระบบ" พร้อมบอกช่วงที่มี — ไม่ใช่ระบบพัง

### บอท AI ตอบเฉพาะสิ่งที่มีหลักฐาน

`BOT_PERSONA` สั่งไว้ว่าห้ามเดา ถ้าข้อมูลไม่พอให้บอกตรง ๆ

นี่คือเหตุผลที่คำตอบสั้น และเป็นสิ่งที่ **ควรคงไว้** สำหรับงานศาล — การผ่อนกฎนี้จะทำให้บอทเริ่มแต่งข้อมูล

### อักขระแฝงที่มองไม่เห็นในข้อความ

ข้อความที่คัดลอกมาวาง โดยเฉพาะจากหน้าเว็บหรือแอปอื่น มักมีอักขระ zero-width space (`U+200B`) ติดมาด้วยโดยไม่แสดงผลอะไรเลย

อักขระตัวนี้ **ไม่ถูกจับด้วย `\s` ใน JavaScript และ `.trim()` ก็ไม่ตัดออก** จึงทำให้คำสั่งที่ดูปกติทุกอย่างไม่ตรงรูปแบบ

อาการที่พบจริง: พิมพ์ `บัญชีนัดความ พรุ่งนี้` แล้วระบบตอบว่า "รูปแบบวันที่ไม่ถูกต้อง" ทั้งที่ `บัญชีนัดความ วันนี้` ใช้ได้ปกติ

เวอร์ชัน 285 เพิ่มการล้างอักขระกลุ่มนี้ (`U+200B` `U+200C` `U+200D` `U+FEFF` `U+00AD` และ non-breaking space) ก่อนตรวจรูปแบบทุกครั้ง เวอร์ชัน 286 ขยายไปใช้กับค่าที่อ่านจากชีตด้วย

### กับดักตอน Deploy

ช่องเลือกเวอร์ชันในหน้า "จัดการการทำให้ใช้งานได้" **มักเด้งกลับไปเป็นเวอร์ชันเดิมเอง** หลังพิมพ์รายละเอียด

ต้องมองให้แน่ว่าช่องอ่านว่า **"เวอร์ชันใหม่"** ในวินาทีก่อนกดยืนยัน ไม่อย่างนั้นจะ Deploy ทับด้วยโค้ดเก่าโดยไม่มีอะไรฟ้อง

### ปุ่มที่ห้ามกด

| ปุ่ม | อยู่ที่ | ถ้ากด |
|---|---|---|
| สร้าง Pikad Trigger | หน้าตรวจสอบระบบ | สร้างทริกเกอร์ซ้ำ งานเบื้องหลังรันซ้อนกัน |
| สร้างโฟลเดอร์อัตโนมัติ | หน้าระบบรับรูป | ชี้ไปโฟลเดอร์ใหม่ ทิ้งรูปหลักฐานเดิมทั้งหมด |

ทั้งสองปุ่มมีไว้กดครั้งเดียวตอนตั้งระบบครั้งแรก ซึ่งกดไปแล้ว

## 7. แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่พบบ่อยที่สุด | ทำอะไร |
|---|---|---|
| ค้นหาแล้วไม่เจออะไรเลยทุกครั้ง | ยังไม่ได้ลงทะเบียนเป็นเจ้าหน้าที่ | ทักบอทในแชทส่วนตัวแล้วพิมพ์รหัสลับ |
| บอทไม่ตอบในกลุ่ม | ไม่ได้พิมพ์ `บอท` นำหน้า | พิมพ์ `บอท ค้นหา …` |
| ถามเรื่องทั่วไปแล้วไม่ตอบ | ไม่มีข้อมูลในคลัง และค้นเว็บปิดอยู่ | เป็นพฤติกรรมที่ตั้งใจ ไม่ใช่ของเสีย |
| บัญชีนัดขึ้นว่าไม่มีข้อมูล | ถามวันที่นอกช่วงที่นำเข้าไว้ | ดูช่วงที่การ์ดบอก แล้วแจ้ง Admin นำเข้าเพิ่ม |
| เข้า Dashboard ไม่ได้ | รหัสอยู่ที่ Script Property ไม่ใช่ในไฟล์เว็บ | ตั้งใหม่ใน Apps Script → การตั้งค่าโปรเจกต์ |
| แก้โค้ดแล้วไม่มีอะไรเปลี่ยน | ยังไม่ได้ Deploy | Deploy เป็น **เวอร์ชันใหม่** และตรวจให้แน่ว่าช่องอ่านว่า "เวอร์ชันใหม่" ก่อนกด |
| ฐานข้อมูลหายไปจากผลค้นหา | คอลัมน์ **สิทธิ์** พิมพ์ค่าที่ระบบไม่รู้จัก จึงถูกปิดไว้ก่อน | แก้เป็น `All` / `Internal` / `Admin` ให้ถูก มีผลทันที |
| คำสั่งที่คัดลอกมาวางแล้วไม่ทำงาน | มีอักขระแฝงติดมา | พิมพ์เองแทนการวาง หรืออัปเดตเป็นเวอร์ชัน 285 ขึ้นไป |
| อยากเปิดบอท AI ให้ทุกคน | `BOT_ACCESS` ยังเป็น `vip` | เปลี่ยนเป็น `all` ในชีต `ตั้งค่า` |

### หมายเหตุเรื่องการอ่าน log

ในบันทึกกิจกรรม ป้าย `Fallback` สถานะ `NotFound` **ไม่ได้แปลว่าระบบพัง** — แปลว่าไม่มีระบบไหนรับงานข้อความนั้น จึงตอบข้อความ "ไม่พบข้อมูล" ไป

(ก่อนเวอร์ชัน 284 ป้ายนี้เขียนว่า `Error` ซึ่งทำให้เข้าใจผิดว่ามีข้อผิดพลาด จึงเปลี่ยนชื่อ)

## 8. ช่องว่างของคู่มือเดิมที่เอกสารนี้ปิดให้

- คู่มือใน LINE **ไม่พูดถึงบอท AI เลย** — ไม่มี `ช่วยหา` หรือ `สอบถาม` อยู่ในการ์ดช่วยเหลือ ผู้ใช้จึงไม่มีทางรู้ว่ามีความสามารถนี้
- ไม่มีที่ไหนระบุว่า `ช่วยหา` กับ `สอบถาม` ทำงานเหมือนกัน
- บัญชีนัดรับ 4 คำนำหน้า แต่คู่มือแสดงแค่บางแบบ
- ไม่มีคำเตือนเรื่องค้นเว็บต้องผูกบิลลิ่ง นอกจากในคำอธิบายช่องตั้งค่า
- ไม่มีตารางสิทธิ์รวมในที่เดียว — ข้อมูลกระจายอยู่ในโค้ด ในชีตฐานค้นหา และในแท็บสิทธิ์คำสั่ง
- ไม่มีที่ไหนระบุว่าระบบอยู่บัญชีไหน ทั้งที่มีโครงการชื่อซ้ำกันหลายอัน
- ไม่มีคำเตือนเรื่องอักขระแฝงจากการคัดลอกข้อความ ทั้งที่เป็นสาเหตุจริงของอาการ "คำสั่งเดิมอยู่ ๆ ก็ใช้ไม่ได้"

## 9. บันทึกการเปลี่ยนแปลง

| เวอร์ชัน | วันที่ | เปลี่ยนอะไร |
|---|---|---|
| 284 | 31 ส.ค. 2569 | เปลี่ยนป้าย log `Error` เป็น `NotFound` · เก็บสาเหตุความผิดพลาดตอนบันทึกรูป · ให้บัญชีนัดตอบเมื่อไม่พบวันที่ |
| 285 | 1 ก.ย. 2569 | ล้างอักขระแฝงก่อนตรวจคำสั่งบัญชีนัด · เพิ่มการ์ด "ถามบอท AI" ในคู่มือ LINE · เพิ่มตารางสิทธิ์และข้อจำกัดในคู่มือแดชบอร์ด |
| 286 | 1 ก.ย. 2569 | สิทธิ์บอท AI ย้ายมาตั้งที่ชีต `BOT_ACCESS` · สิทธิ์ฐานข้อมูลเป็น 3 ระดับ ไม่สนใจตัวพิมพ์ และเปลี่ยนเป็น fail-closed · ปรับคู่มือทุกที่ให้ตรงกัน |
