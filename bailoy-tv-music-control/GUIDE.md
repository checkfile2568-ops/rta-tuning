# คู่มือเพลงทีวี Bailoy

รุ่น 144 - 10 ตุลาคม 2569

## เปิดใช้งานตอนเช้า

1. เปิดทีวีและกล่อง Android เปิด Chrome เข้าลิงก์ [จอทีวี](https://checkfile2568-ops.github.io/rta-tuning/court-tv.html) รอให้ตารางแสดงครบ
2. กดเต็มจอที่ทีวีตามเดิม หากเพลงแสดงปุ่มเปิดเสียง ให้กดหนึ่งครั้ง เบราว์เซอร์เป็นผู้กำหนดสิทธิ์เปิดเสียงและเต็มจอ
3. เปิด [หน้าควบคุมเพลงบนมือถือ](https://checkfile2568-ops.github.io/rta-tuning/court-music.html) เข้าสู่ระบบด้วยบัญชีผู้ดูแลเดิม แล้วเลือกทีวี
4. ทีวีที่จับคู่ไว้แล้วใช้ต่อได้ หากเปลี่ยนเบราว์เซอร์หรือลิงก์และยังไม่จับคู่ ให้กดจับคู่ทีวีบนมือถือ สร้างรหัส แล้วกรอกที่กล่องเพลงของทีวี รหัสมีอายุ 10 นาที
5. เลือกเพลงและรูปแบบวนซ้ำ รอจำนวนโหลดไว้และจำนวนตรวจเก็บไฟล์บนทีวีครบ ก่อนพึ่งการเล่นขณะเน็ตหลุด

หลังรับรุ่นใหม่ ทีวีที่เปิดค้างอยู่ต้องรีเฟรชหนึ่งครั้งในเวลาที่สะดวก การรีเฟรชอาจต้องกดเต็มจอและเปิดเสียงอีกครั้ง

## ใส่เพลงจาก Google Drive

ใช้โฟลเดอร์ MP3 ส่วนตัวที่ตั้งไว้ในระบบเดิม วาง MP3 ในโฟลเดอร์หลัก หรือสร้างโฟลเดอร์ย่อยหนึ่งระดับเป็นอัลบั้ม แล้วใส่เพลงลงในอัลบั้มนั้น ไม่ต้องเปิดไฟล์ให้เป็นสาธารณะ

บนมือถือ กด Drive เลือกโฟลเดอร์อัลบั้มและติ๊กเพลง จากนั้นเลือก:

- **เพิ่มและโหลดไว้:** เพิ่มเพลงลงคลังและให้ทีวีโหลดรายการนี้ หากกำลังเล่นเพลงที่ยังอยู่ในรายการ จะเล่นต่อจากตำแหน่งเดิม หากเปลี่ยนไปอัลบั้มอื่น จะรอให้กดเล่น
- **เพิ่มและเล่นอัลบั้ม:** เปลี่ยนรายการเป็นเพลงที่เลือกแล้วเริ่มเล่น ใช้เสียงและรูปแบบวนซ้ำปัจจุบัน

จำกัด MP3 ไม่เกิน 8 MB ต่อไฟล์ และคลังของทีวีหนึ่งห้องไม่เกิน 30 เพลงตามข้อจำกัดเดิม เพลงที่แก้เนื้อหาใน Drive ต้องนำเข้าใหม่เพื่อสร้างรหัสแคชใหม่ การแก้ไฟล์ไม่ส่งผลทันทีต่อเพลงที่ทีวีเก็บไว้แล้ว

ตัวเลือกอัลบั้มบนหน้าหลักใช้กรองคลัง เมื่อกดเลือกเพลงจากอัลบั้ม รายการที่เล่นจะเป็นเพลงในอัลบั้มนั้น ปุ่มโหลดรายการโหลดเฉพาะอัลบั้มที่เลือก การเปลี่ยนตัวกรองเพียงอย่างเดียวไม่เปลี่ยนเพลงที่กำลังเล่น

ปุ่มเพิ่มเพลงเดิมยังใช้อัปโหลด MP3 จากมือถือหรือเพิ่มลิงก์ HTTPS ของไฟล์เสียงโดยตรงได้ ลิงก์ต้องดาวน์โหลดจากเบราว์เซอร์ได้และอนุญาต CORS ลิงก์หน้าแสดงตัวอย่าง Drive ไม่ใช่ลิงก์ไฟล์เสียงโดยตรง ให้ใช้ปุ่ม Drive สำหรับไฟล์ในโฟลเดอร์ที่ตั้งไว้

## เสียงและการวนเพลง

- เล่น/พัก/หยุด เพลงก่อนหน้า/ถัดไป เพิ่ม/ลดเสียง และปิด/เปิดเสียงควบคุมเฉพาะเสียงเพลงในหน้าเว็บ
- วนหนึ่งเพลงเล่นซ้ำไฟล์ปัจจุบัน วนทั้งอัลบั้ม/รายการเล่นตามรายการแล้วกลับต้นรายการ ปิดวนจะหยุดเมื่อจบรายการ
- ปิดมือถือหรือออกจากระบบ เพลงบนทีวียังเล่นต่อ เปิดมือถือกลับมา เข้าสู่ระบบและเลือกทีวี ระบบอ่านสถานะและเสียงปัจจุบัน ไม่สั่งค่าตั้งต้นทับทีวี
- ซ่อนกล่องตั้งค่าทีวีไม่หยุดเพลง ปุ่มดนตรีจางหายภายใน 3 วินาทีตามเดิม และเรียกกลับด้วยเมาส์/การแตะ หรือปุ่มแสดงตั้งค่าทีวีจากมือถือ

## เมื่อเน็ตหลุด

ไม่มีการรีเฟรชหน้าทีวีอัตโนมัติ ตารางที่โหลดแล้ว นาฬิกา การเลื่อน และการเลือกช่วงเวลายังทำงานในหน้าเดิม เพลงที่โหลดครบเล่นจากไฟล์ที่ทีวีเก็บไว้ การสื่อสารเพลงพยายามเชื่อมต่อกลับ โดยไม่โหลดตารางซ้ำ

หน้ามือถือแสดงทีวีออฟไลน์เมื่อไม่มีสัญญาณใหม่ พร้อมเวลาส่งสถานะล่าสุดและเวลาขาดการเชื่อมต่อ เมื่อเครื่องเล่นกลับมาออนไลน์จึงสั่งการได้อีก คำสั่งที่หมดอายุจะไม่ถูกนำกลับมาทำซ้ำ

สถานะนี้ตรวจการเชื่อมต่อกล่อง/หน้าเว็บ ไม่สามารถรู้ว่าจอทีวีถูกปิดทางไฟฟ้าหรือไม่ หากกล่องและ Chrome ยังทำงานอยู่ การตัดสัญญาณแบบไม่ทันแจ้งอาจใช้เวลาจนสัญญาณครบกำหนดประมาณ 30 วินาที

หาก Chrome ปิด/crash หรือกล่องดับ เพลงหยุดตามอุปกรณ์ Firebase เปิดกล่องหรือ Chrome กลับให้เองไม่ได้ การเริ่มหน้าทีวีใหม่ยังต้องโหลดตารางผ่านอินเทอร์เน็ต แคชเพลงไม่ใช่การรับประกันเปิดระบบทั้งหมดจากการปิดเครื่องขณะไม่มีเน็ต

## สถานะเครื่องเล่นและเครื่องมือทีวี

เปิดหัวข้อบนมือถือเพื่อดูสถานะเต็มจอ หน้าเว็บแสดง/ซ่อน เวลาออนไลน์ และผลคำสั่งจากทีวี

| ปุ่ม | การทำงาน |
| --- | --- |
| เชื่อมต่อเพลงใหม่ | เชื่อมต่อรีโมตเพลงใหม่ โดยคงเพลงและตำแหน่งเดิม ไม่รีเฟรชตาราง |
| ลองเล่น / โหลดใหม่ | ลองการเล่น/ไฟล์เพลงอีกครั้ง และรายงานข้อผิดพลาดจริง |
| เข้าเต็มจอ | ส่งคำขอ หากเบราว์เซอร์ปฏิเสธ ทีวีแสดงปุ่มให้กดยืนยันเอง |
| ออกเต็มจอ | ออกเต็มจอเมื่อเบราว์เซอร์รองรับ |
| ซ่อน / แสดงตั้งค่าทีวี | เปลี่ยนเฉพาะกล่องเพลง |
| รีเฟรชหน้าทีวี | ยืนยันก่อนส่ง แล้วโหลดหน้าใหม่ทั้งตารางและโมดูลเพลง |

รีเฟรชจากมือถือใช้ได้เมื่อเปิดทีวีผ่านลิงก์จอทีวี GitHub ด้านบน หากเปิด Apps Script โดยตรง จะรายงานให้รีเฟรชที่ทีวีเอง เพื่อป้องกันกรอบหน้าเว็บว่าง ปุ่มนี้ไม่ใช้เมื่อเครื่องเล่นออฟไลน์และไม่ทำงานเองเมื่อเน็ตกลับมา

## อ่านผลโหลดไฟล์ให้ถูกต้อง

“โหลดไว้ในทีวี” รวมเพลงที่อยู่ในหน่วยความจำและเพลงบนดิสก์ “ตรวจเก็บไฟล์บนทีวีแล้ว” นับเฉพาะไฟล์ที่เขียน IndexedDB แล้วอ่านตรวจกลับสำเร็จ หากพื้นที่จัดเก็บไม่พร้อม ระบบแจ้งเตือนและไม่อ้างว่าเก็บถาวรครบ

เบราว์เซอร์อาจล้างพื้นที่เก็บไฟล์ได้ หลีกเลี่ยงโหมดไม่ระบุตัวตนและการล้างข้อมูลเว็บไซต์ระหว่างใช้งาน หากไฟล์ยังโหลดไม่ครบและเน็ตหลุด เพลงที่ยังไม่มีไฟล์อาจเล่นไม่ได้ ให้รอออนไลน์แล้วกดลองเล่น/โหลดใหม่

## ขอบเขตที่ตรวจแล้ว

ตรวจซอร์สและโมดูลเซิร์ฟเวอร์ 39 รายการ ตรวจ Chrome 36 สถานการณ์ ตรวจกฎ Firebase จริง 38 รายการ และทดสอบ Auth/ฐานข้อมูลจริง 12 สถานการณ์ในห้องทดสอบแยก รวมถึงปิดมือถือ เปิดกลับ ปรับเสียง ออฟไลน์ วนเพลง และปิดทีวี ห้องและบัญชีทดสอบถูกลบหลังตรวจ

การทดสอบ Firebase ใช้หน้าแอปจริงกับ RPC/บัญชีแอดมินจำลองและเสียงสังเคราะห์ จึงยังไม่ใช่ผลยืนยันบัญชีผู้ใช้จริง ไฟล์ MP3 จริง หรือเสียงจากกล่อง Android ของผู้ใช้ ตรวจหน้าทีวีจริงแบบไม่จับคู่พบตาราง 70 แถวและการรีเฟรชที่สั่งเองโหลดข้อมูลครบ

หลังเผยแพร่ต้องตรวจบนกล่องจริงอีกครั้ง: กดเปิดเสียง ปิดมือถือแล้วฟังต่อ เปิดกลับปรับเสียง ตัดเน็ตหลังโหลดครบให้วนเพลง และตรวจเต็มจอด้วยรีโมต

อ้างอิงข้อจำกัด: [Firebase offline/presence](https://firebase.google.com/docs/database/web/offline-capabilities), [Apps Script iframe](https://developers.google.com/apps-script/guides/html/restrictions)
