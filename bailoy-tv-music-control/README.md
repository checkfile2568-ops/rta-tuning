# Bailoy TV Music Control

หน้าควบคุมเพลงทีวีสำหรับมือถือและคอมพิวเตอร์ ใช้บัญชีแอดมิน ระบบเพลง Firebase และโฟลเดอร์ MP3 เดิม

## รูปแบบการเชื่อมต่อ

ใช้รูปแบบเดียวกับ `court-tv.html` ของ repository เดิม:

GitHub Pages `court-music.html` → iframe Apps Script `/exec?page=music` → `music-control.html` → `Music.gs` / Firebase

GitHub เป็นลิงก์เปิดระบบ ส่วนหน้าควบคุมและการเข้าสู่ระบบยังทำงานใน Apps Script ไม่ใช่การย้ายระบบยืนยันตัวตนไป GitHub หรือการเรียก `google.script.run` จากเว็บไซต์ภายนอกโดยตรง

ไม่มีการเพิ่ม API ใหม่ ไม่มีการเปลี่ยน `doGet` และไม่มีการแก้ TV / ตารางคดี / LINE / ธีมทีวี

## ไฟล์ที่ใช้

- `court-music.html`: หน้าเปิดระบบบน GitHub Pages ตั้งชื่อใหม่ ไม่ทับหน้าเดิม
- `apps-script/music-control.html`: ซอร์สหน้าควบคุมฉบับใหม่ ใช้แทนไฟล์ชื่อนี้ใน Apps Script เท่านั้น ไม่ใช่หน้า HTML ที่เปิดเดี่ยว ๆ บน GitHub ได้
- ไฟล์ `Music.gs`, `MusicCommon.html`, `MusicTV.html` และค่าพร็อพเพอร์ตี้เดิมยังใช้ต่อได้

## นำดีไซน์ใหม่ขึ้น Apps Script

1. สำรองเนื้อหา `music-control.html` ปัจจุบันไว้ในเครื่อง และจดเวอร์ชันเผยแพร่ปัจจุบันก่อนแก้
2. เปิดไฟล์ซอร์ส `apps-script/music-control.html` ของชุดนี้ นำเนื้อหาทั้งไฟล์ไปแทน `music-control.html` ใน Apps Script แล้วบันทึก
3. คงโค้ดและพร็อพเพอร์ตี้อื่นทั้งหมดตามเดิม ไม่เรียกฟังก์ชัน setup ที่อาจตั้ง MUSIC_ENABLED กลับเป็น false
4. ทดสอบ `/dev?page=music` ด้วยแอดมินเดิม: เข้าระบบ เลือกทีวี จับคู่ เล่น/พัก/หยุด เสียง วนเพลง ค้นหา อัปโหลด MP3 และโหลดรายการล่วงหน้า
5. ทดสอบจริงบนทีวี: ปิดหน้าควบคุมแล้วเพลงเล่นต่อ ตัดเน็ตเฉพาะทีวีเมื่อโหลดเพลงครบ และเปิดหน้าควบคุมกลับโดยไม่เริ่มเพลงใหม่
6. เมื่อผ่าน ไปที่การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → เลือก deployment เดิม → แก้ไข → เวอร์ชันใหม่ → ทำให้ใช้งานได้ คง URL และสิทธิ์การเข้าถึงเดิม
7. เปิด GitHub Pages `court-music.html` ตรวจรูปแบบใหม่อีกครั้ง หากยังเป็นแบบเดิมให้ตรวจว่ามีการอัปเดต deployment แล้ว ไม่ใช่เพียงบันทึกโค้ด

## การใช้งาน

เลือกทีวีจากรายการ ปุ่มจับคู่เปิดหน้าต่างเพิ่มทีวี/สร้างรหัสจับคู่ รหัสมีอายุ 10 นาที แยกตามทีวีที่เลือก

คลังเพลงค้นหาภาษาไทยได้ ปุ่มเพิ่มเพลงเปิดไฟล์ MP3 หรือลิงก์ HTTPS จำกัด 8 MB ต่อเพลงตามระบบเดิม ปุ่มโหลดรายการรักษาเพลงและตำแหน่งที่กำลังเล่น

ปุ่มสั่งเพลงใช้สถานะออนไลน์และสัญญาณทีวีจริง ไม่เปิดให้สั่งหากไม่มีสัญญาณใหม่ คำสั่งมีอายุตามระบบเดิมและไม่มีคิวคำสั่งเสียงค้างไว้ระหว่างมือถือออฟไลน์

การออกจากระบบไม่ส่งคำสั่งหยุดเพลง ไม่มีการเก็บรหัสผ่านหรือ session token ของแอดมินไว้ใน browser storage ของหน้าใหม่ การรีเฟรชหน้าต้องเข้าสู่ระบบใหม่

## ความปลอดภัย

ห้ามอัปโหลด JSON service-account, private key, Script Properties export, รหัสผ่าน, session token หรือข้อมูลคดีลง repository

`MUSIC_SERVICE_PRIVATE_KEY` อยู่ใน Script Properties ฝั่งเซิร์ฟเวอร์เท่านั้น GitHub มีเพียงหน้าเปิดระบบและซอร์สหน้าตาที่ไม่มีค่าลับ

หน้าเปิดระบบให้ iframe ใช้เฉพาะ clipboard-write ไม่ขอ camera, location หรือสิทธิ์อื่นที่ไม่จำเป็น

## ผลตรวจและข้อจำกัด

ทดสอบหน้าใหม่ใน Chrome ด้วยบริการจำลอง ไม่ใช่ผลยืนยัน Firebase, MP3, Android หรือการเล่นเสียงในระบบจริง

ตรวจ 33 สถานการณ์: ปุ่มเล่น/พัก/หยุด/เพลงถัดไป/ก่อนหน้า เสียง/ปิดเสียง วนเพลง โหลดรายการโดยไม่เริ่มใหม่ ค้นหาภาษาไทย ข้อผิดพลาด ออฟไลน์ ไม่ส่งคำสั่งค้าง การจับคู่พร้อมหมดอายุ การอัปโหลด การเชื่อมต่อใหม่ การเปลี่ยนทีวีอย่างรวดเร็ว และ viewport 320, 360, 390, 844, 1440 พิกเซล
