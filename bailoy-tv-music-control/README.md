# Bailoy TV Music - รุ่น 144

เพิ่มเพลงจาก Google Drive และเครื่องมือควบคุมทีวีจากมือถือ โดยระบบตารางยังโหลดข้อมูลครั้งเดียวและทำงานในหน้าเดิมเมื่อเน็ตหลุด ไม่มีการรีเฟรชหน้าอัตโนมัติ

GitHub เป็นหน้าเปิด Apps Script เท่านั้น หน้าควบคุมใช้บัญชีผู้ดูแลเดิมและ Firebase เพลงเดิม ไม่ย้ายการตรวจสิทธิ์ไป GitHub

ทีวีที่เปิดค้างอยู่ต้องรีเฟรชเองหนึ่งครั้งเพื่อรับรุ่นนี้ แล้วกดเต็มจอ/เปิดเสียงหาก Chrome ขอ การจับคู่เดิมและเพลงเดิมยังใช้ได้เมื่อเปิดในเบราว์เซอร์และลิงก์เดิม หากย้ายจาก Apps Script โดยตรงมาหน้าทีวี GitHub อาจต้องจับคู่ใหม่ เพราะพื้นที่จัดเก็บในกรอบเว็บอาจแยกกันตามเบราว์เซอร์

## ไฟล์

`apps-script/` เก็บสำเนาโมดูลเพลงที่ตรงกับ Apps Script รุ่น 144 ได้แก่ Music.gs, MusicDrive.gs, MusicCommon.html, MusicTV.html, MusicRemote.html และ music-control.html ไม่ใช่ไฟล์เว็บที่เปิดเดี่ยวบน GitHub

`firebase.database.rules.json` เป็นกฎเฉพาะ Firebase เพลง รองรับสถานะเดิมและสถานะเพิ่มเติม โดยยังปฏิเสธการเข้าถึงระดับ root แยกสิทธิ์มือถือกับทีวีและแยกห้อง

การลงไฟล์ใน GitHub เพียงอย่างเดียวไม่เปลี่ยน Apps Script ต้องอัปเดต deployment เดิมเมื่อปรับโมดูลครั้งต่อไป ห้ามนำ service-account, private key, Script Properties export, session token, รหัสผ่าน หรือข้อมูลคดีมาเก็บใน repository

เอกสารเก่า `TV_PANEL_UPDATE.md` อธิบายรุ่นก่อนหน้า ให้ใช้คู่มือและบันทึกรุ่น 144 สำหรับชุดปัจจุบัน
