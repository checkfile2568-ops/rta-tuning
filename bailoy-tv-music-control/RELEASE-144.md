# ขอบเขตและผลตรวจรุ่น 144

เผยแพร่ Apps Script รุ่น 144 โดยรักษา deployment URL, access และ execute-as เดิม มีสำรองซอร์สและข้อมูล deployment รุ่น 143 ในเครื่องก่อนเริ่ม

## เปลี่ยนเฉพาะส่วนเพลง

- Music: แยกชื่อค่าห้องออกจากค่าอุปกรณ์จับคู่ แก้การเปิดมือถือกลับมาอ่านรายชื่อทีวี และแนบโมดูลคำสั่งเพิ่มเติมผ่าน include เดิม
- MusicTV: ตรวจอ่านแคชกลับ จำกัด RAM เพลง 3 ไฟล์ เชื่อมต่อเพลงกลับแบบหน่วงเวลา เพิ่มข้อมูลดิสก์/เต็มจอ/การแสดงหน้าเว็บ
- music-control: เลือกอัลบั้มจาก Drive สถานะเครื่องเล่นและผลคำสั่ง ปุ่มเครื่องมือทีวี ยืนยันรีเฟรช และไอคอนสำรองเมื่อ CDN โหลดไม่ได้
- เพิ่ม MusicDrive และ MusicRemote แยกจากไฟล์ตารางเดิม
- Firebase: เพิ่มกฎ album, status เพิ่มเติม, lifecycle, remote และ receipt คง default deny และสิทธิ์/ห้องเดิม
- court-tv.html: เพิ่มผู้รับคำสั่งรีเฟรชเฉพาะกรอบทีวี ตรวจ origin, source และ nonce ไม่เปลี่ยน URL/สิทธิ์ iframe/รูปแบบหน้า/การโหลดตาราง
- court-music.html: เพิ่มแถบมือถือออฟไลน์ ไม่สั่งหยุดเพลงและไม่รีโหลดกรอบเองเมื่อเน็ตกลับ

ไฟล์ Apps Script tv, รหัส, admin, index, appsscript, MusicCommon, TestMusicSetup และ InspectMusicKey ตรงกับรุ่น 143 ทุกไบต์ ไม่มีการเขียนข้อมูลคดี/Sheet/LINE/ผู้ใช้/ค่าพร็อพเพอร์ตี้เดิมในการติดตั้งรุ่นนี้ การนำเข้าเพลงของผู้ดูแลในภายหลังเขียนเฉพาะรายการเพลงของห้องที่เลือก

## หลักฐาน

| ชั้นการตรวจ | ผล |
| --- | --- |
| ซอร์สและเซิร์ฟเวอร์จำลอง | 31 รายการ + Drive fixture 8 รายการ |
| Chrome เสียงจริงแบบสังเคราะห์และ transport จำลอง | 36 สถานการณ์ |
| Firebase Security Rules จริง ห้องสุ่ม | 38 รายการ |
| Firebase Auth/RTDB จริง หน้าแอปจริง RPC/แอดมิน/เสียงจำลอง | 12 สถานการณ์ |
| Apps Script จริงแบบไม่จับคู่ | โหลดตาราง 70 แถว รีเฟรชผ่าน wrapper ได้ครบ 5 startup reads ไม่มีกรอบซ้อนเพิ่ม |

ผลข้างต้นไม่ใช่การยืนยันเสียงหรือเต็มจอบน Android TV จริง และไม่ใช่การยืนยันการเข้าสู่ระบบแอดมินจริง การตรวจซอร์ส/อ่านกลับยืนยันไฟล์ระบบสิทธิ์เดิมไม่เปลี่ยน

## ย้อนรุ่น

เลือก deployment เดิมใน Apps Script แล้วเปลี่ยน versionNumber กลับเป็น 143 URL เดิมยังอยู่ หากต้องแก้ซอร์สต่อ ให้กู้ HEAD จากสำรองรุ่น 143 ด้วย ไม่ใช้ชุด patch โมดูลเพลงแทนทั้งโครงการ

กฎ Firebase รุ่นใหม่รองรับสถานะทีวีรุ่นเก่า จึงย้อน Apps Script ได้โดยไม่ต้องลบห้อง เพลง หรือการจับคู่ หากต้องคืนกฎเดิมใช้สำรอง rules-before ที่ตรวจอ่านจากระบบก่อนอัปเดต ห้ามลบฐานข้อมูลทั้งโครงการ

การแก้หลังจากนี้ควรสำรองและอ่านกลับ HEAD ล่าสุดก่อนเสมอ ไม่รัน TestMusicSetup เพื่อติดตั้งซ้ำ เพราะอาจเปลี่ยนค่าตั้งไว้แล้ว
