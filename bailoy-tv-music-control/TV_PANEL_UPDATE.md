# อัปเดตกล่องเพลงของทีวี

ไฟล์สำหรับ Apps Script: `apps-script/MusicTV.html`

## สิ่งที่เปลี่ยน

- ปรับกล่องเพลงของทีวีเป็นพื้นขาว ขอบบาง ปุ่มสีเขียว และไอคอนดนตรี
- หลังซ่อนกล่อง ปุ่มดนตรีมุมซ้ายล่างค่อย ๆ จางหายภายใน 3 วินาที
- เลื่อนเมาส์ผ่านมุมซ้ายล่างเพื่อแสดงปุ่ม แล้วกดปุ่มเพื่อเปิดกล่อง
- บนมือถือ แตะหน้าจอเพื่อแสดงปุ่ม แล้วแตะปุ่มดนตรีเพื่อเปิดกล่อง
- เมื่อเรียกปุ่มด้วยการแตะหน้าจอ ปุ่มจะแสดง 3 วินาทีก่อนเริ่มจางหายอีกครั้ง
- ถ้ากล่องเปิดอยู่ หรือปุ่มมีโฟกัสจากคีย์บอร์ด ปุ่มจะไม่จางหาย
- Escape ซ่อนกล่องและคืนโฟกัสให้ปุ่มดนตรี

ไม่มีการเปลี่ยนตารางคดี การประกาศ การแจ้ง LINE ระบบสิทธิ์ Firebase คำสั่งเพลง หรือแคชเสียงเดิม การซ่อนกล่องไม่หยุดเพลง

## ติดตั้งในระบบเดิม

1. เปิด Apps Script ของระบบใบลอยที่ใช้งานจริง และสำรองเนื้อหา `MusicTV.html` เดิมก่อน
2. แทนเนื้อหาทั้งหมดของไฟล์ **MusicTV.html** ด้วยไฟล์ในโฟลเดอร์ `apps-script` นี้ โดยไม่สร้างชื่อซ้ำ
3. บันทึก ไม่ต้องแก้ `tv.html`, `MusicCommon.html`, `Music.gs`, `music-control.html` หรือพร็อพเพอร์ตี้ของสคริปต์
4. เปิดการทำให้ใช้งานได้ → ทดสอบการทำให้ใช้งานได้ แล้วทดสอบ URL `/dev?page=tv` ในบัญชีที่มีสิทธิ์แก้ไขโปรเจ็กต์
5. ตรวจการจับคู่ เล่นเสียง ซ่อนกล่อง การจางหาย 3 วินาที และเรียกปุ่มกลับด้วยเมาส์/มือถือ
6. เมื่อผ่าน ให้เปิดการทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไขรายการเว็บแอปเดิม → เลือกเวอร์ชันใหม่ → ทำให้ใช้งานได้ เพื่อรักษา URL `/exec` เดิม
7. รีเฟรชหน้าทีวีในช่วงที่สะดวก การรีเฟรชจะเริ่มหน้าใหม่และอาจต้องกดเปิดเสียงอีกครั้งตามข้อจำกัดของเบราว์เซอร์

GitHub `court-tv.html` เป็นหน้าครอบ Apps Script เดิม ไม่จำเป็นต้องแก้ไฟล์นั้น การเพิ่มไฟล์นี้ลง GitHub เพียงอย่างเดียวยังไม่ทำให้กล่องบนทีวีจริงเปลี่ยน

## ผลตรวจสอบ

ทดสอบใน Chrome บนเครื่องด้วย backend/Firebase จำลอง และ HTMLAudioElement จริงที่เล่น WAV ทดสอบ:

- UI 16 รายการ: จางหาย เมาส์ สัมผัส คีย์บอร์ด จับคู่ ผิดรหัส เชื่อมต่อใหม่ และเลย์เอาต์ 320–1920 พิกเซล
- ระบบเดิม 26 รายการ: เริ่มทีวี คดีตามวัน/เวลา ปิดมือถือ ออฟไลน์ แคชเพลง วนเพลง เปลี่ยนเพลง และสถานะเล่นจริง
- บล็อกการเล่นเสียง แคช IndexedDB และการส่งสถานะคงเดิมตรงกับไฟล์ต้นฉบับ

ยังไม่ได้ทดสอบกับ Firebase จริง ลำโพงจริง หรือทีวีจริง และไม่ได้อัปเดต Apps Script โดยอัตโนมัติ ไม่มีคีย์ลับหรือข้อมูลคดีจริงอยู่ในไฟล์นี้

ย้อนกลับได้โดยคืนเนื้อหา `MusicTV.html` ที่สำรองไว้ แล้วอัปเดต deployment เดิมเป็นเวอร์ชันใหม่
