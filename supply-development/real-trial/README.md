# ทดสอบบนฐานข้อมูลจริง และล้างกลับยอดเริ่มต้น 0

API/หน้าเว็บรุ่น 1.3.0 ใช้โครงการ Apps Script และ URL เดิม เพิ่มเมนู **ทดสอบฐานจริง / ล้างยอด** โดยคงเมนูสร้าง–ล้างข้อมูลจำลองเดิมไว้

## ใช้งาน

1. แอดมินเปิดเมนูทดสอบฐานจริง กด **เริ่มรอบทดสอบจริง** และพิมพ์ `เริ่มทดสอบจริง` ระบบยอมให้เริ่มเมื่อยอดและเอกสารรับ–จ่ายเป็น 0 เท่านั้น พร้อมบันทึกสำเนาจุดเริ่มต้น
2. กด **เติมตัวอย่าง 10 รายการในฐานจริง** หรือเพิ่มวัสดุและรับเข้าเอง ตัวอย่างใช้ใบเสนอราคา QT-2026/1107 ก่อน VAT รวม 6,811 บาท ปากกา 12 กล่องแปลงเป็น 120 ด้าม
3. เจ้าหน้าที่และผู้ใช้เข้าไอดีจริงของตนเอง ใช้หน้าเบิก คิวจ่าย รับเข้า รับคืน ตรวจนับ สถิติ และกระทบยอดตามปกติ ไม่ต้องเข้าพื้นที่จำลอง
4. เมื่อจบทดสอบ แอดมินกด **ล้างข้อมูลทดสอบจริง กลับยอด 0** และพิมพ์ `ล้างกลับยอด 0` ระบบคืนทะเบียนและการตั้งค่าก่อนเริ่มรอบ ย้อนการเพิ่ม/แก้ไขระหว่างรอบ และทำให้ยอดรับ–จ่ายกลับ 0
5. นำเข้ายอดยกมา/ทะเบียนจริงก่อนเริ่มงานประจำ หลังล้างรอบจะปิด ปุ่มล้างจะไม่เปิดใช้กับงานประจำที่ไม่ได้อยู่ในรอบทดสอบ

ทะเบียนวัสดุที่มีอยู่ก่อนเริ่มรอบยังอยู่ตามสำเนาจุดเริ่มต้น ตัวอย่างเริ่มต้นของระบบมี 5 รายการยอด 0 วัสดุและรายการที่เพิ่ม/แก้หลังเริ่มรอบจะถูกย้อนกลับ คง **บัญชี สิทธิ์ และส่วนงานล่าสุด** ไว้ ไม่ย้อนบัญชีกลาง PrintHub หรือข้อมูลพื้นที่จำลอง

## การกู้คืน

รอบก่อนล้างเก็บไว้ทั้งชุด ไม่ลบไฟล์ถาวร แอดมินใช้ **กู้คืนก่อนล้างล่าสุด** ได้เมื่อยังไม่มีงานหรือการแก้ไขข้อมูลหลังล้าง ระบบตรวจทั้งยอด 0 และลายนิ้วมือข้อมูลก่อนกู้ จึงไม่กู้ทับทะเบียนที่เพิ่งเพิ่มแม้จำนวนคงเหลือยังเป็น 0

## การป้องกันข้อมูลค้าง

- รหัสรอบข้อมูลจริงเปลี่ยนทุกครั้งที่เริ่ม ล้าง หรือกู้คืน ทุกคำขอเขียนตรวจรหัสอีกครั้งภายใน stock lock
- หน้าเก่าต้องรีเฟรชก่อนบันทึก ผลสำเร็จ UUID เก่าไม่ถูกนำมาเล่นซ้ำข้ามรอบ
- Catalog ตะกร้า ร่าง และคิวส่งในเครื่องแยกตามรอบ ร่างเก่าไม่ถูกส่งเข้าฐานใหม่หลังโหลดหน้าใหม่
- การล้างเตรียมสำเนายอด 0 ให้ครบก่อนสลับฐานที่ระบบใช้งาน เก็บฐานก่อนล้างไว้ รหัสฐานและรหัสรอบอ้างอิงจาก JSON property เดียวกัน
- ชื่อข้อมูลในฐานจริงและบัญชีรับ–จ่ายมีผลจริงระหว่างรอบ ทุกคนเห็นแถบแจ้งรอบทดสอบฐานจริง เอกสารพิมพ์ระบุว่าเป็นรอบทดสอบ
- ระหว่างรอบไม่ส่งข้อความ LINE ค่าแจ้งเตือนเดิมในระบบไม่ถูกแก้
- แอดมินเท่านั้นเริ่ม เติม ล้าง และกู้คืน เจ้าหน้าที่คงสิทธิ์งานพัสดุเดิม
