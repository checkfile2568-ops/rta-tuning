## โครงสร้างระบบ

```text
ผู้ใช้งาน
  → GitHub Pages (docs.html)
  → Google Apps Script Web App
  → Google Sheets / Google Drive
```

GitHub Pages ทำหน้าที่เป็นหน้าเปิดระบบและฝัง Web App ผ่าน iframe ส่วนการจัดการข้อมูล การแนบรูป การจัดทำเอกสาร และการพิมพ์ ทำงานใน Google Apps Script

## การแก้ไขระบบหลัก

ซอร์สของ Google Apps Script ถูกเก็บไว้ในโฟลเดอร์ `apps-script/` และซิงก์กับ Script ID `1X9EndGiZflGWzCGg2kVRdnIs5uZXbsO5NEpRjryTUivW45Fk6vFRGV0K` ผ่าน `clasp`:

```text
apps-script/
├─ รหัส.js
├─ legal-doc-system.html
└─ appsscript.json
```

ห้ามเก็บรหัสผ่าน, API key, token หรือข้อมูลส่วนบุคคลใน GitHub ให้ใช้ Script Properties หรือการตั้งค่าที่ Google Apps Script จัดการแทน

## ขั้นตอนอัปเดตอย่างปลอดภัย

1. ดึง/สำรองซอร์สจาก Google Apps Script ก่อนแก้ไข
2. แก้ไขและทดสอบในหน้า Web App โดยเฉพาะมือถือแนวตั้งและแนวนอน
3. อัปโหลดซอร์สด้วย `clasp push` แล้วตรวจทานที่ Apps Script
4. สร้างเวอร์ชันและ Deploy ใหม่จาก Google Apps Script เมื่อตรวจรับแล้ว
5. หาก URL `/exec` เปลี่ยน ให้แก้ `src` ใน `docs.html`
6. Commit และ Push ไฟล์ที่เกี่ยวข้องขึ้น GitHub
7. เปิด GitHub Pages เพื่อตรวจการใช้งานจริงอีกครั้ง

## การปรับปรุงในชุดโค้ดนี้

- มีแถบปุ่ม **แนบรูปภาพ** และ **จัดทำเอกสาร** ทั้งในหน้าและแบบลอย โดยปุ่มจัดทำเอกสารจะพร้อมใช้เมื่อเลือกคดีแล้ว
- รองรับมือถือแนวตั้ง/แนวนอน พร้อมตารางคดีแบบการ์ดบนจอแคบ
- รายงานประจำเดือนเลือกและเปิดข้อมูลรายวันผ่านปฏิทิน: วันที่บันทึกแล้วเป็นสีเข้ม วันที่ว่างเป็นสีจาง
- เก็บและรวมยอดแยกตามเลขบัลลังก์/ห้องพิจารณาคดี โดยเลขบัลลังก์จากคอลัมน์ E ของชีตไม่ถูกส่งไปพิมพ์ในรายงานกระบวน
