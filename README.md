## การแก้ไขระบบหลัก

ซอร์สของ Google Apps Script ควรเก็บในโฟลเดอร์ `apps-script/` ของ Repository นี้ เมื่อดึงจากโปรเจกต์หลักได้แล้ว:

```text
apps-script/
├─ Code.gs
├─ appsscript.json
├─ *.html
├─ *.js
└─ *.css
```

ห้ามเก็บรหัสผ่าน, API key, token หรือข้อมูลส่วนบุคคลใน GitHub ให้ใช้ Script Properties หรือการตั้งค่าที่ Google Apps Script จัดการแทน

## ขั้นตอนอัปเดตอย่างปลอดภัย

1. ดึง/สำรองซอร์สจาก Google Apps Script ก่อนแก้ไข
2. แก้ไขและทดสอบในหน้า Web App โดยเฉพาะมือถือแนวตั้งและแนวนอน
3. Deploy เวอร์ชันใหม่จาก Google Apps Script
4. หาก URL `/exec` เปลี่ยน ให้แก้ `src` ใน `docs.html`
5. Commit และ Push ไฟล์ที่เกี่ยวข้องขึ้น GitHub
6. เปิด GitHub Pages เพื่อตรวจการใช้งานจริงอีกครั้ง

## งานปรับปรุงที่กำลังเตรียม

- แสดงปุ่ม **แนบรูป** และ **จัดทำเอกสาร** ให้เห็นเสมอบนมือถือหลังเลือกคดี
- รองรับมือถือแนวตั้งและแนวนอนโดยไม่เกิดการเลื่อนแนวนอน
- เพิ่มรายงานประจำเดือนแบบปฏิทิน และสรุปตามเลขบัลลังก์/ห้องพิจารณาคดี
- เก็บข้อมูลห้องพิจารณาคดีเพื่อคำนวณยอด แต่ไม่แสดงในเอกสารที่พิมพ์

## การเผยแพร่

GitHub Pages ใช้ Repository นี้บน branch `main` จากโฟลเดอร์ราก (root) หลัง Push แล้วอาจใช้เวลาเล็กน้อยก่อนหน้าเว็บจะอัปเดต
