# Roadmap

## Phase 1–5 — ชุดปัจจุบัน
- Architecture / Database / RLS
- Windows Agent / Heartbeat
- Dashboard Online / Warning / Offline
- CPU / RAM / Disk / Uptime
- Lock / Sleep / Hibernate / Restart / Shutdown
- Shutdown Timer / Cancel

## Phase 6
- Device pairing ด้วย QR Code
- Roles และหลายอุปกรณ์

## Phase 7–9
- App allowlist / Open URL / Worker / Backup / Volume
- Screenshot / Clipboard แบบผู้ใช้กดอนุญาต

## Phase 10–12
- Virtual Display integration
- Remote screen แบบ low latency
- Mouse / Keyboard remote และ Multi-display

Remote Display จะไม่ส่ง frame ผ่าน Database และจะไม่เขียน Kernel Driver ใหม่โดยไม่จำเป็น
