## รูปแบบคำสั่งมาตรฐาน

### แชทส่วนตัว
- `ค้นหา <คำค้น>` — ค้นฐานความรู้และฐานค้นหาตามสิทธิ์
- `ค้นหา [ชื่อฐาน] <คำค้น>` — เจาะฐานเฉพาะ
- `บัญชีนัด วันนี้` / `บัญชีนัด พรุ่งนี้` / `บัญชีนัด มะรืน` / `บัญชีนัด 14 สิงหาคม 2569`
- `ศูนย์ประสานงานคดี` — เปิดเมนูศูนย์ประสานงานคดีออนไลน์
- `/ช่วยเหลือ` หรือ `/help` — ดูคู่มือฉบับย่อ

### กลุ่ม LINE
- `/บอท ค้นหา <คำค้น>` — ค้นฐานความรู้และฐานค้นหา
- `/บอท ค้นหา [ชื่อฐาน] <คำค้น>` — เจาะฐานเฉพาะ
- **บัญชีนัดเรียกตรงได้**: `บัญชีนัด วันนี้`, `บัญชีนัด พรุ่งนี้`, `บัญชีนัด 14 สิงหาคม 2569`
- **ไม่ต้องใช้ `บอท` นำหน้าคำสั่งบัญชีนัด**

## การติดตั้ง patch
1. สร้าง Script ใหม่ใน Apps Script ชื่อ `HelpGuideV3` แล้ววางไฟล์ `help_command_patch_v3.gs`
2. เปิด `Dashboard.html` และวาง `dashboard_help_patch_v3.html` ก่อน `</body>`
3. ใน message router เดิม ให้เรียก `tryUnifiedHelpCommand_(text)` ก่อน Search/Court/KB fallback แล้วใช้ reply function เดิมส่ง `helpResult.text`
4. Save → Deploy เวอร์ชันใหม่
5. ทดสอบ `/ช่วยเหลือ` ในแชทส่วนตัวและกลุ่ม
6. ทดสอบ `บัญชีนัด วันนี้` ในกลุ่ม โดย **ไม่ใส่บอทนำหน้า**
7. ทดสอบ `/บอท ค้นหา [เขตส่งหมาย] ท่าแค` และ `/บอท ค้นหา [เวรเสื้อฟ้า] ชนินทร์`

> หมายเหตุ: บางกลุ่มที่ถูกกำหนดเป็น PIKAD-only จะปิด KB+DB Search ตามการตั้งค่าเดิมของระบบ
