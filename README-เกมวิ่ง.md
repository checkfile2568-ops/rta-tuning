# เกมวิ่งแข่ง 3D — คู่มือติดตั้งและใช้งาน (ต้นแบบระยะ 1)

ในชุดนี้มีหน้าจอเกม 3D สำหรับเปิดบนโปรเจคเตอร์ (`run.html`) และหน้าจอยสำหรับมือถือ (`pad.html`)
ผู้เล่นสแกน QR แยกเลน P1 / P2 แล้วกำมือถือแกว่งแขน ตัวละครจะวิ่งตามความเร็วที่แกว่ง

## ไฟล์ในชุด

| ไฟล์ | หน้าที่ |
| --- | --- |
| `run.html` | จอเกม: สร้างห้องและ QR, ฉาก 3D ลู่สีฟ้า, ตัวละครการ์ตูน, ตรรกะการแข่ง, เสียง |
| `pad.html` | จอยบนมือถือ: เปิดเซนเซอร์, คาลิเบรต, จับการแกว่งแขน, ส่งความเร็ว |
| `run-net.js` | ส่วนเชื่อมต่อที่ทั้งสองหน้าใช้ร่วมกัน (Firebase / โหมดทดสอบในเครื่อง) |
| `assets/run/` | Three.js, QR และ Firebase SDK ที่เก็บไว้ใน repo เพื่อไม่ต้องโหลดจาก CDN ระหว่างเล่น |
| `assets/run/sfx/manifest.json` | รายการไฟล์เสียงจริง (ว่างไว้ก่อน เกมจะใช้เสียงสังเคราะห์แทน) |

ไฟล์ไลบรารีที่เก็บไว้ใน `assets/run/` ใช้รุ่น Three.js 0.160.0, qrcode-generator 1.4.4 และ Firebase compat 10.12.2 พร้อมข้อความสิทธิ์ใช้งาน `THREE-LICENSE.txt`, `QRCODE-LICENSE.txt`, `FIREBASE-LICENSE.txt`

## ติดตั้ง (ครั้งเดียว)

1. คัดลอกทั้งหมดไปไว้ที่โฟลเดอร์รากของ repo `rta-tuning` แล้ว push
2. เปิดจอเกมที่ `https://checkfile2568-ops.github.io/rta-tuning/run.html`
3. เกมใช้ฐานข้อมูลเริ่มต้นของโปรเจกต์นี้โดยอัตโนมัติ ถ้าต้องเปลี่ยนฐานข้อมูล ให้กด **S** แล้ววาง Database URL หรือ firebaseConfig ก่อนกด "บันทึก + เชื่อมต่อใหม่"
4. Firebase → Realtime Database → **Rules** เพิ่มบรรทัดนี้ต่อจากกฎเดิม (ไม่ต้องลบของเดิม) แล้วกด Publish

```
"games": { ".read": true, ".write": true }
```

มือถือไม่ต้องตั้งค่าอะไร เพราะ QR มีค่าการเชื่อมต่อแนบไปด้วยแล้ว

**ใช้กับคอมเครื่องอื่น:** บนเครื่องที่ตั้งค่าแล้ว กด **S** → "🔗 คัดลอกลิงก์ตั้งค่า" แล้วเปิดลิงก์นั้นบนคอมเครื่องใหม่ครั้งเดียว เครื่องนั้นจะจำค่าไว้เอง (เก็บลิงก์ไว้ส่วนตัว เพราะมีที่อยู่ฐานข้อมูลอยู่ในลิงก์)

## วิธีเล่น

1. เปิด `run.html` บนคอมที่ต่อโปรเจคเตอร์และลำโพงแบบต่อสาย เลือก **เล่นคนเดียว** หรือ **เล่น 2 คน** แล้วคลิกที่จอ 1 ครั้งเพื่อเปิดเสียง กด **F** เพื่อเต็มจอ
2. ผู้เล่นสแกน QR ตามเลนที่แสดง (คนเดียวแสดง P1 เลนแดง; สองคนแสดง P1 และ P2)
3. บนมือถือ กด "เริ่ม · เปิดเซนเซอร์" (iPhone จะถามอนุญาต ให้กดอนุญาต)
4. คาลิเบรต: แกว่งแขนเร็วที่สุด 5 วินาที (ทำครั้งเดียวต่อเครื่อง)
5. เมื่อมือถือเชื่อมและคาลิเบรตครบตามจำนวนที่เลือก ปุ่ม **เริ่มเล่น** บนจอเกมจะกดได้ กดแล้วเกมนับ 3-2-1 และสั่ง "เข้าที่ – ระวัง – ปัง"
6. แกว่งแขนให้เร็วที่สุด ถ้าขยับก่อนเสียงปืนจะโดนฟาวล์ ครั้งแรกเตือนแล้วเริ่มใหม่ ครั้งที่สองออกตัวช้ากว่าคนอื่น 1 วินาที
7. จบแล้วกด "อีกรอบ" บนมือถือ หรือกด Enter ที่คอม จากนั้นจอเกมกด **เริ่มเล่น** สำหรับรอบถัดไป

## ปุ่มลัดบนจอเกม

| ปุ่ม | ทำอะไร |
| --- | --- |
| F | เต็มจอ |
| S | ตั้งค่า (Firebase, ระดับเสียง, คุณภาพภาพ) |
| K | โหมดคีย์บอร์ด สำหรับทดสอบโดยไม่ใช้มือถือ: P1 กด A/D สลับกัน, P2 กด ←/→ สลับกัน, Space = พร้อม |
| Enter | ในล็อบบี้: เริ่มเมื่อผู้เล่นตามโหมดเชื่อมครบแล้ว · ในหน้าผล: กลับไปล็อบบี้ |
| Esc | ยกเลิกรอบที่กำลังแข่ง |
| R (กด 2 ครั้ง) | สร้างห้องใหม่ (ผู้เล่นต้องสแกน QR ใหม่) |
| 1 / 2 (กด 2 ครั้ง) | นำผู้เล่น P1 / P2 ออกจากเลน |

## เสียง

- เกมสังเคราะห์เสียงทั้งหมดเอง ได้แก่ เสียงผู้ชม เสียงปรบมือ เสียงเท้า เสียงหายใจ เสียงปืน นกหวีด แตรตอนเข้าเส้นชัย และเพลงสั้นตอนประกาศผล
- เสียงพูด "เข้าที่ / ระวัง" และการประกาศผู้ชนะใช้เสียงพูดภาษาไทยของเบราว์เซอร์ ถ้าเปิดด้วย **Microsoft Edge** จะได้เสียงไทย ส่วน Chrome บน Windows มักไม่มีเสียงไทย จึงเป็นเสียงบี๊ปแทน
- ถ้าจะใส่เสียงจริงแทน ให้วางไฟล์ใน `assets/run/sfx/` แล้วแก้ `manifest.json` ตามตัวอย่างนี้ (ใส่เฉพาะเสียงที่มี เสียงที่ไม่ใส่จะใช้เสียงสังเคราะห์)

```json
{
  "crowd": "crowd.mp3",
  "step": ["step1.mp3", "step2.mp3", "step3.mp3"],
  "gun": "gun.mp3",
  "whistle": "whistle.mp3",
  "horn": "horn.mp3",
  "fanfare": "fanfare.mp3",
  "marks": "marks.mp3",
  "set": "set.mp3",
  "breathIn": "in.mp3",
  "breathOut": "out.mp3"
}
```

## ปรับจูนหลังทดสอบกับคนจริง

- ตารางแปลงจังหวะแกว่งเป็นความเร็วคือ `SPEED_TABLE` ซึ่งอยู่ทั้งใน `pad.html` และ `run.html` ถ้าแก้ต้องแก้ให้ตรงกันทั้งสองไฟล์
- เกณฑ์นับก้าวคือ `THR_RATIO = 0.35` ใน `pad.html` (35% ของแรงที่คาลิเบรตได้)
- เวลาของนักวิ่งเงาเริ่มต้นคือ `PACE` ใน `run.html` (60 ม. = 11 วินาที, 100 ม. = 18 วินาที) เมื่อมีคนทำสถิติแล้ว เงาจะวิ่งตามสถิติที่ดีที่สุดแทน
- ใส่ `?debug=1` ต่อท้ายลิงก์จอยบนมือถือ เพื่อดูค่าเซนเซอร์สด ๆ

## ทดสอบบนคอมเครื่องเดียว (ไม่ใช้ Firebase)

เปิด `run.html?local=1` แล้วคลิกลิงก์ "เปิดจอย P1 ในแท็บใหม่" ใต้ QR หรือกด K เพื่อใช้คีย์บอร์ด

## ข้อควรรู้

- ต้องให้ผู้เล่นคล้องสายข้อมือ ยืนห่างกันอย่างน้อย 1.5 ม. และหันหน้าเข้าจอ
- คอมและมือถือต้องมีอินเทอร์เน็ต เพราะส่งข้อมูลผ่าน Firebase
- สถิติและตารางอันดับเก็บไว้ในเบราว์เซอร์ของคอมจอเกม (localStorage)
- ตัวละครทั้งหมดสร้างด้วยโค้ด ไม่ต้องโหลดโมเดล ถ้าจะเพิ่มตัวละครใหม่ให้แก้ที่ `STYLES` ใน `run.html`
