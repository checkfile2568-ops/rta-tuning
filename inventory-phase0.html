ตรวจการเชื่อมต่อจากเบราว์เซอร์

ต้องเปิดหน้านี้จาก GitHub Pages จริงเพื่อรับรอง CORS ห้ามใช้ URL preview แทนผลทดสอบจริง และห้ามกรอก PIN หรือข้อมูลบัญชีจริง

ยังไม่ได้รันทดสอบ

รายการทดสอบผลจริงเวลา msRedirect

บันทึก Browser/OS จาก user agent ไว้ในหลักฐาน ผลทดสอบไม่รวมกุญแจหรือ token ต้องทดสอบ Chrome, Edge และ Safari บน iPhone แยกกัน
