            บัญชีนัดความไม่เจอข้อมูล
            1. ตรวจ COURT_STATUS = ON และ COURT_SHEET_ID ถูกต้อง

                2. ตรวจชื่อชีตใน COURT_SHEET_NAME เช่น Database

                3. ถ้าข้อมูลอยู่ชีตสำรอง ให้ใส่ชื่อใน COURT_FALLBACK_SHEETS		
          

          

            ศูนย์ประสานงานคดีออนไลน์ไม่ตอบ
            1. เปิด ONLINE_COURT_STATUS = ON

                2. ตรวจช่องขอบเขตการตอบ ONLINE_COURT_GROUP_IDS เช่น all, groups, private หรือ C/R/U ID ให้ตรง

                3. ตรวจวันเวลา ONLINE_COURT_DAYS, ONLINE_COURT_START_TIME, ONLINE_COURT_END_TIME		
          

          

            ไม่ได้รับ Flex หลังส่งพิกัด
            1. Run setupPikadSessionTrigger

                2. เช็ค PIKAD_SYSTEM_URL ในชีต ตั้งค่า

                3. Deploy version ใหม่		
          

          

            VIP ลงทะเบียนไม่ได้
            1. ส่งรหัสใน private chat เท่านั้น (กลุ่มไม่ได้)

                2. ตรวจ VIP_SECRET_CODE ในชีต ตั้งค่า (default: VIP2026)

                3. ตอบชื่อ-นามสกุลเมื่อบอทถาม (พิมพ์ /ยกเลิก ถ้าจะยกเลิก)		
          

          

            กำหนดการไม่ส่งอัตโนมัติ
            1. Run setupScheduleTrigger ใน Apps Script

                2. ตรวจ Triggers menu ต้องมี runScheduledNotify

                3. เช็ค NOTIFY_STATUS = ON		
          

          

            TV Notify ไม่ทำงาน
            1. ใส่ TV_NOTIFY_URL + TV_NOTIFY_TARGETS และเปิด TV_NOTIFY_STATUS

                2. Run setupTVNotifyTrigger

                3. ทดสอบด้วย testTVNotifyNow		
          

          

            ระบบช้า / แจ้ง warmUp ยังไม่ตั้ง
            warmUp เป็น Trigger ทางเลือก หากยังไม่ได้รัน setupWarmUpTrigger ระบบจะแจ้งว่า "ยังไม่ตั้ง" แต่ไม่กระทบการรับงานหมาย
