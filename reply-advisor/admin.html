จัดการข้อมูลกลาง

📊 เปิดฐานคำตอบ Google Sheetแก้สั้น/ปกติ/ละเอียด, Keyword, Risk, ข้อความใช้บ่อย และเบอร์ติดต่อ🖼️ เปิดคลังรูป/เอกสารเก็บภาพและเอกสารที่ใช้ประกอบการตอบ
✅ ฐานกลางพร้อมแล้ว
Google Sheet มี AnswerPacks, QuickReplies, Contacts, Media, Suggestions, Config และ AuditLog แล้ว ระบบถูกออกแบบให้ไม่บันทึกข้อความประชาชนลง AuditLog โดยค่าเริ่มต้น

ขั้นตอนเปิดใช้การ Sync ทุกเครื่อง

  1. เปิด Google Sheet ด้านบน
  2. เลือก Extensions → Apps Script
  3. นำโค้ดจาก Code.gs ไปวาง
  4. Deploy → New deployment → Web app
  5. Execute as: Me และ Who has access: Anyone
  6. คัดลอก URL ที่ลงท้าย /exec
ทำไมต้องกด Deploy เอง?
Google ให้เจ้าของบัญชียืนยันสิทธิ์ Web App ครั้งแรกด้วยตนเอง หลังจากได้ URL /exec แล้วสามารถนำมาเชื่อมหน้าเว็บได้ทันที

โครงสร้างการใช้งาน

Google Sheet = ฐานคำตอบกลาง
Google Drive = คลังรูป/เอกสาร
GitHub Pages = หน้าใช้งาน
Browser Cache = สำรองเมื่อฐานกลางเข้าไม่ได้
